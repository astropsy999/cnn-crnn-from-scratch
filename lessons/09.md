Статья: [Урок 9. Empty-детектор «как в проекте»](https://stuzhuk.page/ru/blog/cnn-crnn-from-scratch-09-ablation/)

## Что появилось

- `configs/empty-detector.yaml` — рецепт в одном файле
- `src/config.py`, `src/imbalance.py`, `src/early_stopping.py`, `src/selection.py`, `src/ablation.py`
- `src/models/empty_detector.py` — TinyCNN + Dropout
- `src/train_empty_detector.py` — обучение по конфигу
- `experiments/ablate_imbalance.py` — абляция none/weights/sampler/both
- тесты конфига, дисбаланса, ранней остановки, выбора эпохи, абляции и модели

## Команды

```bash
python src/train_empty_detector.py --config configs/empty-detector.yaml
python experiments/ablate_imbalance.py --backend logreg --seeds 3
python experiments/ablate_imbalance.py --config configs/empty-detector.yaml --seeds 3
python -m pytest tests/test_config.py tests/test_imbalance.py tests/test_early_stopping.py tests/test_selection.py tests/test_ablation.py tests/test_empty_detector.py tests/test_ablate_harness.py -q
```

## Ожидаемое

- чекпоинт с порогом; лучшая эпоха по empty_recall при value_recall ≥ 0.99
- абляция: mean ± std, победитель по val, вердикт
- pytest: `34 passed`

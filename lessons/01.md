## Что появилось

- `requirements.txt` — зависимости курса (`torch`, `numpy`, `Pillow`, `matplotlib`, `pyyaml`, `pytest`)
- `src/device.py` — `pick_device()`: cuda → mps → cpu
- `src/seed.py` — `set_seed`, `make_generator`, `seed_worker`
- `src/check_environment.py` — версии, устройство, один тензорный расчёт
- `experiments/check_determinism.py` — один seed → одинаковый отпечаток весов
- пустые `data/`, `tests/`

## Команды

```bash
python src/check_environment.py
python experiments/check_determinism.py
```

## Ожидаемое

- `check_environment.py` печатает версии, `Device` и `Tensor OK`
- `check_determinism.py` заканчивается строкой `determinism: OK (hash match)` и кодом 0

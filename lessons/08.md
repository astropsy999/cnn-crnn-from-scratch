## Что появилось

- `src/choose_threshold.py` — выбор порога (пишите сами на start)
- `src/stats.py` — интервал Уилсона
- `src/inference.py`, обновлённый `src/train_tiny_cnn.py`
- `experiments/plot_threshold_curve.py`
- тесты порога, статистики и отчёта

## Команды

```bash
python src/train_tiny_cnn.py --data-dir data/processed --epochs 10 --out checkpoints/tiny_cnn.pt
python src/choose_threshold.py --checkpoint checkpoints/tiny_cnn.pt --data-dir data/processed --save-scores experiments/tiny_cnn_scores.npz
python experiments/plot_threshold_curve.py --scores experiments/tiny_cnn_scores.npz --out experiments/threshold_curve.png
python -m pytest tests/test_choose_threshold.py tests/test_stats.py tests/test_threshold_report.py -q
```
